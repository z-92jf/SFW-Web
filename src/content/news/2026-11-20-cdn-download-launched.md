官网今天多了一条下载通道：**dl.sfw.us.ci**。

## 为什么要加这一条

GitHub 在国内的毛病不是打不开页面，是**下载会断**。页面能加载，点下载也能开始，但一个 6 MB 的安装包有时候会下到一半停住，得重试几次。

这个问题在 Releases 页面上尤其明显，因为那个页面本身加载就慢，等它转完再点下载，又可能断在半路。

所以这次的改动很简单：把同一个文件放到 Cloudflare 上，多给一个入口。

## 现在点下载是什么样

以前点「立即下载」就直接跳 GitHub 了。现在会**先弹一个小窗口**，让你选走哪条路：

- **GitHub Release** —— 从官方仓库拉，国外或者网络好的时候没问题
- **Cloudflare** —— 从 dl.sfw.us.ci 拉，国内通常更快

两条通道下的是**同一个文件**，只是来源不同，随便选一个就行。弹窗右上角的叉、点空白处、按 ESC 都能关掉。

## 上面放了哪些版本

不是只有最新版。

`1.0.0` 到 `1.1.3` 一共 6 个版本，每个版本都有安装程序和免安装包，合起来 12 个文件，全部放上去了。

想装回旧版的话，不用再去 GitHub 的 Releases 里翻。去官网的[历史版本](/history)页面点那个版本，弹窗里走 Cloudflare 那条就行。

## 顺便加了文件校验

下载最怕的是下完了打不开，还搞不清是文件坏了还是软件本身有问题。

现在弹窗底部有一块**「文件MD5值」**，默认收起，点开能看到当前这个版本的安装包和免安装包各一个 MD5。下载站 `dl.sfw.us.ci` 的页面上，每个版本也都标了对应的值。

核对的办法：打开 PowerShell，进到文件所在的目录，跑这一行：

```powershell
Get-FileHash .\Setup.SERVICES.FOR.Windows.1.1.3.exe -Algorithm MD5
```

它会打印一串 32 位的十六进制，和页面上那个值对比就行。对得上说明文件完整，对不上就重新下一次。

Windows 自带这个命令，不用装任何东西。

## 一点说明

下载站是刚建好的，如果你打开 `dl.sfw.us.ci` 看到 404 或者加载不出来，多半是还没部署完，过几分钟再试。

官网那条 GitHub 通道没有取消，两条都在。以后如果哪条出了问题，另一条还能用。
