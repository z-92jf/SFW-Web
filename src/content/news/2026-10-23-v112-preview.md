1.1.2 还在做，先把已经跑起来的部分说一声。

## main.cpp 被拆了

1.1.1 的 main.cpp 有 2265 行，登录、注册、菜单、五子棋、进制转换、管理器全挤在一个文件里。

现在拆成了八个模块：

| 模块 | 负责 |
|---|---|
| `common` | 全局变量、输入函数、系统辅助 |
| `bin_to_dec` | 进制转换 |
| `first_start` | 首次启动配置 |
| `five_stones_go` | 五子棋 |
| `setting` | 设置中心 |
| `app_theme` | 主题 |
| `WinManager` | Windows 多功能管理器 |
| `update` | 检查更新 |

main.cpp 剩 1277 行，只留主流程：首页、登录、注册、主菜单、游戏大厅、服务中心和初始化。

功能没变，界面也没变。这次动的全是内部结构。

## 能自己检查更新了

这是 1.1.2 里最实用的一项。

程序启动时会去官网拉一个 `version.txt`，里面写着最新版本号。如果比你手上的新，就提示一下。

几个细节：

- 24 小时内只查一次，不会每次开都去请求
- 网络不通就静默跳过，不拖慢启动
- 只提示并给下载链接，不会偷偷替换你的程序

## 三个新功能

**主题**：内置三套配色（默认、蓝底、亮底）。可以查看当前主题、切换、恢复默认。选择会存下来，下次打开还是那个。

**设置中心**：现在只有一个入口，就是主题设置，其他项还空着。

**首次启动配置**：会先做一次硬件检测，确认键盘按键正常，然后带你过一遍安全输入键盘的用法。要输入 `111`、输入 `abcABC123`、按 `Ctrl` 切换明文显示。
