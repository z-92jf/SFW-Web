经过一段时间的准备，**SERVICES FOR Windows 的新官网今天正式上线了**。

新地址：<https://sfw.us.ci>

## 为什么重做官网

原来的站点用的是几年前的博客模板，首页是一串文章列表，访客进来第一眼看不到"这是什么软件、能做什么、怎么下载"。这次按产品官网的思路重新做了一遍：

- 首页第一屏直接讲清产品定位，并给出下载入口
- 增加**界面预览**，四张截图轮流展示各个功能模块
- **历史版本**搬到站内列表，不用再忍受 GitHub Releases 页面加载慢
- 补上完整的**帮助文档**和**许可证**页面

## 这次上线包含什么

| 板块 | 地址 | 说明 |
|---|---|---|
| 首页 | `/top` | 功能概览、界面预览、常见问题 |
| 新闻 | `/news` | 就是你现在看的这一块 |
| 下载 | `/download` | 最新版安装包 |
| 历史版本 | `/history` | 往期版本列表 |
| 更新日志 | `/changelog` | 逐版本的改动记录 |
| 帮助 | `/help` | 完整使用说明 |
| 许可证 | `/license` | 许可条款与免责声明 |

## 关于新闻板块

这个板块用来发布开发进展、使用技巧和活动通知。每篇文章都是一个 Markdown 文件，写完提交到仓库，网站会自动更新 —— 不需要动任何网页代码。

文章可以按**时间**、**发布者**、**主题**三种方式归类，也可以用页面上的搜索框直接找内容。
