> 我们的软件内置了初始化功能

### （九）进制转换工具

#### 1.功能介绍

SERVICES FOR Windows内置了一个进制转换工具，支持三种转换方式：

| 方式 | 说明 |
|---|---|
| 十进制 → 任意进制 | 输入一个十进制数，转换为您指定的进制 |
| 任意进制 → 十进制 | 输入一个指定进制下的数，转换为十进制 |
| 任意进制 → 任意进制 | 输入任意进制下的数，转换为另一种进制 |

- **进制范围**：2 ~ 36
- **数值范围**：约 -9.22×10¹⁸ ~ 9.22×10¹⁸（超出范围可能出现错误结果或乱码）
- **转换结果可以一键复制**到剪贴板

#### 2.进入方式

**第一步** 在主程序菜单中，键入 `2` 选择“SERVICES FOR Windows主程序”。

**第二步** 在下一级菜单中，键入 `2` 选择“进制转换工具”。

#### 3.使用说明

进入工具后，界面会列出三种转换方式，<span style="background-color:rgb(255, 238, 173)">按一下对应按键即可选择，不需要按回车</span>：

| 按键 | 功能 |
|:---:|---|
| `a` / `A` / `1` | 十进制 → 任意进制 |
| `b` / `B` / `2` | 任意进制 → 十进制 |
| `c` / `C` / `3` | 任意进制 → 任意进制 |

**方式一：十进制 → 任意进制**

1. 输入您想转换成的**目标进制**（2 ~ 36），按回车
2. 输入要转换的**十进制数**，按回车
3. 界面显示转换结果

**方式二：任意进制 → 十进制**

1. 输入**原数的进制**（2 ~ 36），按回车
2. 输入该进制下的**数值**，按回车
3. 界面显示转换结果

**方式三：任意进制 → 任意进制**

1. 输入**原数的进制**（2 ~ 36），按回车
2. 输入该进制下的**数值**，按回车
3. 输入**目标进制**（2 ~ 36），按回车
4. 界面显示转换结果

> **注意区分两种操作**：选择转换方式只需要**按键**（不用回车）；而输入进制和数值时需要**按回车**确认。

#### 4.结果操作

显示结果后，可以按以下按键继续操作：

| 按键 | 作用 |
|:---:|---|
| `c` / `C` | 把结果**复制到剪贴板** |
| `b` / `B` | 返回进制转换界面（重新选择转换方式） |
| `e` / `E` | 退出工具，返回上一层菜单 |

复制成功时程序会给出提示；如果因为未知原因复制失败，也会有相应说明。

#### 5.注意事项

- **大于十的进制请使用大写字母输入**。例如十六进制的 255 应输入 `FF`，如果输入小写 `ff`，计算出的结果**是不正确的**。
- **请勿超出数值范围**。超过约 ±9.22×10¹⁸ 时，结果可能出现错误或乱码。
- **进制必须在 2 ~ 36 之间**，否则结果没有意义。
- 输入不合法的**进制数**或**十进制数**时，程序会提示并要求您重新输入。
- 输入**任意进制数值**时，请确保每一位都是该进制的合法字符（`0`~`9`、`A`~`Z`），否则结果可能不正确。

## 四、隐私与安全性

### （一）关于隐私

#### 1.数据收集

SERVICES FOR Windows软件<span style="background-color:rgb(255, 238, 173)">不收集</span>**任何**用户数据。z-92jf加法工作室不需要您的数据。

#### 2.账户信息

您在SERVICES FOR Windows注册的账号均为**离线账号**，账号信息均被保存于您的设备。SERVICES FOR Windows软件<span style="background-color:rgb(255, 238, 173)">不收集</span>**任何**账户信息。z-92jf加法工作室不需要您的数据。

### （二）关于安全性

#### 1.数据存储

##### -1-存储方式

SERVICES FOR Windows软件将您的数据存储在**本地**，而非云端。这意味着您无法进行任何联机操作，并且为了实现离线功能，我们的软件没有自动更新功能。这意味着安全性将显著提升，但是联机体验将不太友好。

您的账号信息保存在**程序所在目录**中（即与程序文件放在同一个文件夹里）。因此请注意：

- **移动程序时，请连同整个文件夹一起移动**。不要把程序文件单独复制或剪切到别处，否则账号数据不会跟着走。
- 无论您从哪里启动程序（桌面快捷方式、其它程序调用等），读取的都是同一份数据，不会出现“换个地方打开就看不到账号”的情况。
- 想备份账号时，直接把程序目录下的数据文件复制一份即可。

##### -2-数据安全性

我们的数据部分以.txt文件储存于本地，但是Password文件和Users文件的安全性**较差**，我们会考虑尽快修复这个问题。

我们的用户在输入密码时**自动**隐藏密码内容。这极大地保护了用户的隐私。

#### 2.账户注册限制

SERVICES FOR Windows在引导用户进行注册时采取了一些保护措施，帮助用户提升账号安全性。

##### -1-两次验证密码

我们要求您在注册的最后再次输入密码以确认您输入了正确的密码。这旨在帮助用户容错率的提升。

##### -2-强密码保护

我们对注册时的新密码做了**强制**强密码保护，这旨在为用户的账号提升安全性。
